# Credit Card Fraud Detection

## Objective
Detect fraudulent credit card transactions using machine learning.

## Dataset
Kaggle Credit Card Fraud Detection Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Models Used
- Logistic Regression
- KNN
- Decision Tree
- Random Forest

## Best Model
Random Forest

## Results
- Precision: 0.95
- Recall: 0.79
- F1 Score: 0.86
